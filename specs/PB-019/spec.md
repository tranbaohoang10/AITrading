# PB-019 — chart/image analysis (Issue #25)

An authenticated owner submits one bounded PNG/JPEG chart and an optional research
question. The server decodes and re-encodes it before a provider-neutral multimodal
call. Only a strictly validated result separating visible evidence, visible text,
inferences, missing data, confidence and limitations is persisted and returned.

Images and visible text are untrusted evidence, never instructions. No URL, tool,
code execution, live data, profitability claim or automatic Strategy DSL mutation
exists in this operation. A strategy requires the separate PB009 review/accept path.
